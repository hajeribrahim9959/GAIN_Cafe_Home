GAIN Café - Vintage Luxury Homepage

1. Open the GAIN_Cafe_Home folder in VS Code.
2. Open a terminal in that folder.
3. Run: pip install -r requirements.txt
4. Run: python app.py
5. Visit: http://127.0.0.1:5000

Includes a responsive bilingual Arabic/English homepage with your GAIN visuals.
The map button searches the Quriyat–Afa area; it is not a verified café pin.
The gallery and menu are visual demonstrations, not live online ordering.

3D Gift: Open /gift or click 3D Gifts in navbar. Three.js requires internet access.

3D Coffee Cup: click 3D Cup in navbar, or visit /static/gain_3d_cup.html directly. Internet is required to load Three.js.
